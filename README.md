# Smoking and Health Analysis Dashboard

Healthcare analytics project for Sapphire IQ, built in Excel.

## Files
- `Smoking_Health_Analysis_Dashboard.xlsx` – dashboard, analysis tables, data and notes
- `Smoking_Health_Analysis.csv` – original patient-level dataset (10,000 rows)

## What's inside
- **Dashboard:** 4 KPIs, 6 charts, Gender and Region filters (dropdowns)
- **Analysis:** formula-based summary tables for each objective
- **Data:** raw data + calculated columns (Age Group, BP Risk Category, Smoking Exposure)
- **Notes:** assumptions and insights

## Note
Completed in Excel because Power BI Desktop does not run on macOS.
This is exploratory analysis only and does not establish medical diagnoses or prove that smoking causes any condition.
